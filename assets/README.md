# V1.6 實際整合素材包

此資料夾為完整 72 件獨立素材母版；相同檔案複製於正式本機專案的 `assets/`，由 `v15-ui.js` 以相對路徑載入。角色姿勢、頭像、六面骰、棋盤格、食物、操作和回饋圖示均用於實際遊戲畫面或對應狀態，不是只有預覽圖。V1.6 由每位真人玩家在開局前自行選擇造型，六面骰在棋盤中央逐面翻動。

PNG 均為含 alpha 的 RGBA，SVG 均有 viewBox 且不依賴外部檔案。角色與頭像由 Codex imagegen 逐件生成；簡單物件與圖示為 Codex 逐件繪製的原生向量稿並輸出。參考概念圖只用於風格方向，未裁切成素材。素材來源已如實記錄；第三方商用授權未作聲明。

開啟 `preview.html` 可在白、深、棋盤格背景逐件查看。`manifest.json` 含尺寸、用途、來源及整合欄位。正式題庫照片仍放於專案 `images/questions/`，本素材包不替換題目照片。

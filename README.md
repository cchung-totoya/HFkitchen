# 營養廚房大冒險 V1.7

這是以 `data/players.csv` 與 `data/questions.csv` 為正式資料來源的 20 格配膳教育遊戲。支援 2–4 人輪流、單人與電腦對戰、文字題 8 秒與圖文題 30 秒倒數、學習歷程與 Excel 成果匯出。首頁採角色卡片與大型模式選項；遊戲畫面使用專案 `assets/` 中可獨立載入的 72 件素材。

## 啟動

線上版：[GitHub Pages](https://cchung-totoya.github.io/HFkitchen/#home)。管理者將新版正式 CSV、題目圖片及程式推送至 GitHub `main` 後，待 Pages 完成發布，各電腦重新開啟或整理頁面便會重新讀取正式 CSV。玩家與題庫資料透過 GitHub 更新；**各瀏覽器的遊戲歷程仍各自保存在本機**，不會跨電腦同步。

Windows 解壓縮下載包後，進入 `kitchen-monopoly` 資料夾，雙擊 `start.cmd`。瀏覽器會開啟 `http://127.0.0.1:8765/`；遊戲期間保留命令視窗，按 Ctrl+C 可停止。同資料夾重複啟動會開啟既有畫面。若通訊埠被另一個資料夾佔用，先關閉舊視窗，再從本版資料夾啟動。請勿直接雙擊 `index.html`，瀏覽器對 `file://` 頁面的 CSV 讀取有限制。

## 選角與擲骰

開始遊戲前先勾選真人玩家，再為**每位已勾選的玩家**選擇營養師、廚師或另一款廚師造型；沒有預設造型，未選齊不能開局。四位玩家可重複選擇同款，棋子外框顏色仍可區分；電腦對手使用專屬電腦圖示。造型選擇只保存在當次遊戲和其歷史場次，不改正式玩家 CSV。遊戲中的六面骰顯示於地圖中央，按下擲骰後會翻動骰面、顯示最終點數，再移動棋子；偏好減少動態效果的裝置會縮短動畫。

首頁的「玩法說明」可查看完整規則；「管理與成果」選單可前往玩家名單、正式題庫和學習成效。文字題限時 8 秒，圖文題維持 30 秒，兩者均有視覺進度條；逾時記為未作答且本題 0 分。原有答對得分、答錯不扣分及獎勵／事件格分數維持不變。答題後立即顯示正確答案、解析與本題分數。

## 更新正式玩家、題庫與圖片

`data/players.csv` 與 `data/questions.csv` 是唯一正式玩家及題庫來源；每次啟動或重新整理都重新讀取，不以 localStorage 的舊名單或題庫覆蓋。管理者在本機使用時編輯專案內 CSV 並整理頁面；使用 GitHub Pages 時須將變更推送至 GitHub `main`，待 Pages 更新後整理頁面。「管理與成果」中的玩家與題庫頁為唯讀檢視，不能直接修改 CSV。詳細欄位與圖片路徑見 [DATA-UPDATE.md](DATA-UPDATE.md)。

圖文題的 `Source`、`QuestionImage` 或 `OptionImageA`–`OptionImageD` 請填 `questions/檔名.jpg` 等相對路徑，圖片實際放在 `images/questions/`。此資料夾是正式題目照片；`assets/` 是遊戲介面美術，兩者用途不同。Excel 檔要用「另存新檔 → CSV UTF-8」，不能只將 `.xlsx` 改名為 `.csv`。

## 學習歷程與匯出

同一瀏覽器、同一網址下，`localStorage` 保存場次、作答與進行中遊戲，可繼續遊戲；不保存正式玩家名單或整份題庫。強制結束會保存已完成歷程。學習成效頁可匯出四張工作表的 Excel（玩家總表、答題明細、題目分析、遊戲場次）、答題明細 CSV 及完整 JSON 備份。電腦作答不計入人員學習成效。清除遊戲紀錄前請先匯出備份；此操作不修改正式 CSV。
